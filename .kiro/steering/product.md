# Product Overview

Tiny Trae is a minimal AI coding agent powered by Anthropic's Claude with a modular frontend architecture. It serves as a terminal-based AI assistant for software engineering tasks.

## Core Purpose
- Interactive AI coding assistant that runs in the terminal
- Executes predefined tools based on Claude's responses
- Helps with software development tasks through natural language interaction

## Key Features
- **Interactive Chat**: Terminal-based conversation with the AI agent
- **Non-interactive Mode**: Single prompt execution for automation
- **Tool Execution**: Built-in tools for file operations, code search, and shell commands
- **Extensible Architecture**: Modular design allows easy addition of new tools and frontends
- **Multiple Profiles**: Different configurations (default, minimal, closeai) for various use cases
- **Trace Recording**: Detailed logging of model interactions for debugging

## Target Users
Developers who want a lightweight, terminal-based AI assistant for coding tasks without the overhead of complex IDEs or web interfaces.
